Print from any PC on your LAN,
to a printer attached to another PC.

PrintLink is a peer-to-peer printer-sharing agent for small offices. No cloud. No accounts. No Windows printer sharing. Jobs travel encrypted, PC-to-PC.

 Requires Windows 10/11

How it works

1

Share a printer

On the PC with the printer, share it under a friendly alias from the tray icon.

2

Add it from another PC

Enter the host PC's 9-digit ID. The host gets an accept/refuse dialog — nothing prints without permission.

3

Right-click to print

Right-click any document and choose Print with PrintLink. A preview dialog lets you pick the target printer, copies, pages, paper, color and duplex before anything leaves your machine.

Features

Print preview dialog

Choose the destination printer and print options (copies, page range, paper, color, duplex, orientation, fit) with a rendered first-page preview.

Per-PC grants, not accounts

Access is granted PC-to-PC with 9-digit IDs. Grants expire automatically (default 7 days) and can be revoked or extended any time from the tray.

Encrypted jobs

Every job is encrypted with AES-256-GCM keyed by the pairing token, then delivered directly between agents over HTTP — no central server in the path.

No virtual printer, no drivers

No port monitors, no admin rights per share. The receiver renders by format: PDF (PyMuPDF + SumatraPDF), Word (COM), images (GDI+), text (spooler).

Automatic discovery

Agents find each other via mDNS on the LAN, with a stored-IP fallback when mDNS is blocked by VLANs or switches.

Works for every user on a PC

Data is shared machine-wide, so every Windows account on a PC sees the same printers and can use the right-click verb.

Requirements

  • Windows 10 or 11 on every PC (the share logic and HTTP API are cross-platform; printing uses Windows features).
  • Host PC: SumatraPDF installed for PDF printing; Microsoft Word for .docx/.doc documents.
  • PCs on the same LAN; firewall port TCP 9100 opened (the installer does this for you on the Private profile).

Setup

Working in three steps

No servers to configure and no driver installs — both sides just run the same tray agent.

1

Share a printer

On the PC with the printer, share it under a friendly alias from the tray icon.

2

Add it from another PC

Enter the host PC's 9-digit ID. The host gets an accept/refuse dialog — nothing prints without permission.

3

Right-click to print

Choose Print with PrintLink. Pick destination, copies, pages, paper, color and duplex in a live preview before anything leaves your machine.

Product

Built like a product, not a hack

Everything below ships in one ~50 MB installer — agent, right-click verb, firewall rules.

Live print preview

First-page thumbnail plus a one-line summary of exactly what will be sent — copies, page range, paper, mono/color, duplex, orientation, fit.

Per-PC grants that expire

Access is granted PC-to-PC with 9-digit IDs. Grants expire automatically (default 7 days, capped at 90) and can be revoked or extended any time from the tray.

Tokens never cross the wire

Every request proves possession of the pairing secret with an HMAC over a one-time nonce — sniffing traffic yields neither credentials nor payload keys.

No virtual printers, no drivers

No port monitors, no per-share admin rights. The receiver renders natively by format: PDF, Word, Excel/PPT, images, plain text.

mDNS discovery with fallback

Agents find each other automatically on the LAN; if multicast is blocked by VLANs or switches, a stored IP is used — always re-verified before use.

One PC, every account

The shared printer list is machine-wide, so all Windows accounts see the same printers — while pairing tokens stay private to each user's profile.

Security

Encrypted end-to-end, authorized end-to-end

Designed for trusted office LANs — and hardened so a curious colleague can't become a problem.

  • HMAC challenge auth. The pairing token is never transmitted — requests carry a proof over a single-use nonce.
  • AES-256-GCM payloads. Tampering fails decryption and never reaches your printer.
  • Identity verified per send. The sender confirms the machine at the resolved IP really owns the dialed ID before anything sensitive moves.
  • Private token storage. Grants live in a per-user database — one Windows account can't read another's credentials.

Get started

Install it on every PC

Run the installer on each machine — it registers the right-click verb, opens the firewall for LAN printing, and starts the tray agent. Updates arrive in-app.
